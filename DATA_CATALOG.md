# 📊 DATA CATALOG

> *A forensic inventory of the UI_INDEX data, with file organization, provenance, audit controls, and versioned lineage.*

**Metadata Standard:** Every JSON data file carries a `_metadata` block:
- `generated_by` — which script produced it
- `generated_at` — timestamp
- `data_sources` — BLS, DOL, HUD, FEC, Census, Congress.gov, USASpending, FRED
- `methodology` — how the numbers were calculated
- `caveat` — known limitations

**Data Freshness:** October 20, 2026 — BLS September 2026 CPS + LAUS August 2026 integrated.

## 4. Refresh Pipeline (Ordered)

To regenerate all data and figures from scratch:

```bash
# 1. Fetch all live data
python fetchers/fetch_fred_inflation.py
python fetchers/fetch_bls_baselines.py
python fetchers/fetch_housing.py
python fetchers/fetch_dol_sui_rates.py
python fetchers/fetch_usaspending.py
python fetchers/fetch_county_data.py

# 2. Run analysis engines
python -m ui_index.core_engine
python -m ui_index.employer_models
python -m ui_index.fec_pipelines
python -m ui_index.political_layer_builder

# 3. Generate all figures
python tools/generate_figures.py
python tools/generate_rvi_figure.py
python tools/generate_employer_gap_charts.py
python tools/generate_fec_charts.py
python tools/generate_context_figure.py
python tools/generate_spending_accountability.py
python tools/generate_county_map.py
python tools/generate_plotly_charts.py

# 4. Run delta analysis
python -m ui_index.delta_analyzer

# 5. Validate
pytest tests/ -v
```

**Automated refresh:** `.github/workflows/data_refresh.yml` runs monthly (1st of month, 06:00 UTC) and auto-commits results.

## 5. Quality Checklist

Before any data release:

- [ ] All JSON files contain `_metadata` blocks
- [ ] All figures (13 PNGs) are present and non-empty
- [ ] `pytest tests/ -v` passes
- [ ] BLS data is current (check [bls.gov/lau](https://www.bls.gov/lau/) for latest)
- [ ] CPI data reflects most recent month
- [ ] FEC data uses correct cycle filter (2024 for current analysis)
- [ ] No PII or secrets in any file
- [ ] `OPTIMIZATIONS.md` updated with any corrections
